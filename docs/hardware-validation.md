# 实机验证记录

日期：2026-10-22。环境：Ubuntu 22.04.5 LTS，AirPods Pro 3。
这份记录不包含设备蓝牙地址、用户配置文件或原始备份。

## 授权与连接

1. 耳机已配对并连接，BR/EDR ATT PSM `0x001f` 可连接。
2. 未配置 Apple DeviceID 时，读取通透句柄 `0x0018` 返回 `01 0a 18 00 0e`。
3. 用户运行仓库配置工具，设置 `DeviceID = bluetooth:004C:0000:0000`，重启蓝牙并重新连接耳机。
4. 再次读取成功，参数布局为 104 字节。

## 读取与写入

初始值：自定义通透关闭；左右耳增音、音调、环境噪声降低均为 0；对话增强关闭；
自己声音增音为 0.5。

执行修改：`enabled=true`，左右耳 `amplification=-0.2`。
工具在写入前保存完整原始值，收到 ATT Write Response 后读回，完整参数字节与请求一致。
随后关闭 ATT 连接，在另一次独立连接上重新读取，仍得到相同值。
实际浮点读数为 `-0.20000000298023224`，是 −0.2 的 float32 表示。

音调、环境噪声降低、对话增强和自己声音增音没有修改。

- 蓝牙重连、切换到苹果设备、耳机重启之后的参数保持行为。

读回一致证明设备接受并保存了该参数值，不等同于证明它在所有聆听模式下都产生预期声音效果。
